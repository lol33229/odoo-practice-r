# Сервис+ — US №1 «Поиск исполнителя»

Реализация первой user story проекта «Сервис+»: каталог мастеров с рейтингом,
отзывами и фильтрами по цене, географии и срочности.

---

## 1. Что реализовано (маппинг критериев приёмки → код)

| Критерий приёмки | Как реализовано |
|---|---|
| Открываю каталог услуг (сантехник, электрик, сварщик, уборка снега) | Модель `service.category` + kanban-каталог `service.provider`, сгруппированный по категории |
| Вижу рейтинг и отзывы о каждом исполнителе | `service.review`, поле `rating` — вычисляемое среднее (`_compute_rating`, `@api.depends`) |
| Фильтр по цене | Поля `price_from`/`price_to` + фильтры в `search view` (`price_low`, `price_mid`, `price_high`) |
| Фильтр по географии (близость к магазину) | Поле `distance_km` + фильтры `dist_near` / `dist_mid` / `dist_far` |
| Фильтр по срочности | Поле `urgency` (Selection) + фильтры `urgency_urgent` / `urgency_standard` / `urgency_scheduled` |
| Вижу ориентировочную стоимость | Диапазон `price_from`–`price_to` показан прямо на карточке kanban и в форме |

## 2. Структура модуля

```
service_plus/
├── models/
│   ├── service_category.py   # Категории услуг (Сантехник, Электрик...)
│   ├── service_provider.py   # Мастера: цена, гео, срочность, рейтинг (compute)
│   └── service_review.py     # Отзывы (оценка 1-5 + комментарий)
├── views/
│   ├── service_category_views.xml
│   ├── service_provider_views.xml   # kanban-каталог + фильтры
│   ├── service_review_views.xml
│   └── service_menu_views.xml
├── security/
│   └── ir.model.access.csv
├── __init__.py
└── __manifest__.py
```

### 3.1. Обнови список приложений

- Зайди в **Apps**
- Убери фильтр "Apps" (если есть) в поиске, либо сразу нажми на выпадающее меню (⋮ / шестерёнку) → **Update Apps List** → **Update**

### 3.2. Установи модуль

- В поиске набери **Сервис+**
- Нажми **Install**
---

## 4. Возможные проблемы при первом запуске

| Проблема | Причина | Решение |
|---|---|---|
| Модуль не появляется в Apps | Не обновлён список приложений | Apps → Update Apps List |
| Рейтинг не пересчитывается | Забыл сохранить отзыв / не обновил форму мастера | Сохрани отзыв, обнови страницу мастера |
