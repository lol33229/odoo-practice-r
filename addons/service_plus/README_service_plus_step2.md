# Сервис+ — роль «Исполнитель услуг», US №1 «Получение заказов»

---

## 1.реализация

| Критерий приёмки | Как реализовано |
|---|---|
| Отображается список доступных заказов | Kanban-каталог `service.order`, по умолчанию отфильтрован по статусу «Новая» (`state='new'`) |
| Фильтр по расстоянию, стоимости, виду работ | Search view: фильтры `dist_near/mid/far`, `price_low/mid/high`, группировка по `category_id` |
| Видны адрес, описание, фотографии | Поля `address`, `description`, `photo_ids` (галерея фото через дочернюю модель `service.order.photo`) |
| Можно откликнуться на заказ | Кнопка **«Откликнуться»** на карточке и в форме открывает мастер (`service.order.response.wizard`)  создаёт запись `service.order.response` |

---

## 2. Новые модели

```
service.order            — заявка на услугу (адрес, категория, бюджет, расстояние, статус)
service.order.photo      — фотографии, прикреплённые к заявке (One2many)
service.order.response   — отклик исполнителя на заявку (кто, сколько просит, статус)
service.order.response.wizard  — всплывающая форма отклика (кнопка "Откликнуться")
```
